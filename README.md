## 📊 Sobre o Projeto

Este repositório contém a solução do desafio prático da **Formação Power BI Analyst da DIO**, ministrado pela expert Juliana Zanelatto. O objetivo foi criar um relatório completo e interativo no Power BI com base no dataset `Financial Sample`.

O projeto foi desenvolvido do zero e publicado no **Power BI Service**, seguindo todas as diretrizes do desafio.

## 🖼️ Páginas do Relatório

### **Página 1: Sales Report**
Dashboard executivo com visão geral de vendas. Contém KPIs de Receita Total, Unidades Vendidas, Descontos e COGS. Análise de vendas por mês, segmento, produto e país com botões para alternar entre gráficos de barras, pizza e treemap.

### **Página 2: Report de Lucro Detalhado**
Análise aprofundada de lucratividade. Utiliza gráfico de decomposição para explorar o lucro por ano e país, além de visuais de radar para produtos, treemap para segmentos e waterfall para lucro trimestral.

## 🛠️ Tecnologias e Recursos Utilizados

- **Microsoft Power BI Desktop**
- **Power BI Service** para publicação
- **DAX** para criação de medidas
- **Visuais Nativos**: Cartão, Gráfico de Linhas, Barras, Pizza, Treemap, Decomposição, Radar, Waterfall
- **Recursos de UX**: Botões de navegação, Segmentadores, Tooltips, Drill-down
